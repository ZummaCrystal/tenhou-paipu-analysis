# v1.3.1

v1.3.1 稳定版（首个正式发布的 1.3.1）。

## 相对 v1.3.0 的变化

- **界面整体放大 25%**：工具栏、特征面板、事件列表、牌桌按同一比例放大，高分屏下不再显得偏小。
- **检索结果分段载入**：一次载入 1000 条，翻段时自动载入下一段（旧版只能看到前 100 条，且没有进入后面的手段）。
- **静态帧禁用右上角「局」下拉**：静态帧只通过「上一条目 / 下一条目」切换。
- **数据库兼容判据放宽**：只要「大版本 + 中版本」相同即可继续使用已有库（v1.3.1 能读 v1.3.0 建的库，反之亦然）。
- **修复：AI 决策表「其它」行按显示值补足到 100.0%**（见下）。
- 沿用 v1.3.0 的能力：天凤 / NAGA / Mortal 三种牌谱的下载与播放、40 个特征（第零类 5 + 第一类 17 + 第二类 17 + 第三类 1）的打点入库与分段检索。

## 本次修复：AI 决策表「其它」行

- **现象**：某帧只有一张牌过 10% 门槛、其概率为 99.54%（显示成 `99.5%`）时，右侧 AI 决策表里没有「其它」行，表内合计看起来只有 99.5%。
- **原因**：旧逻辑按**原始万分比**判断残差（不足 0.5% 不补这一行），而显示用的是一位小数 —— 那 0.04 个百分点正好让两者落在阈值两侧。
- **现在**：`其它 = 100.0% − 表内已显示选项的显示值合计`（不足 0.1% 不显示）⇒ 表内合计总是 100.0%；上例会补出 `其它 0.5%`。
- **影响范围**：只是播放界面右侧决策表的显示。牌谱解析、特征计算与入库、检索结果都不受影响，已有数据库不需要重建。

## 安装与升级

- Windows 安装包（NSIS 向导），安装到当前用户目录。
- **数据库兼容**：只要「大版本 + 中版本」相同即可继续使用已有库；本次数据库结构未变化（schema 10），**不需要重新分析牌谱**。
- 用户数据（牌谱 / 数据库 / 日志）保存在 `%LOCALAPPDATA%\tenhou-paipu-analysis\`，卸载不会删除。
- 若您此前拿到过本地构建的 1.3.1 测试包（143,286,767 B / SHA256 `F95F577A…`），请以本包为准。
