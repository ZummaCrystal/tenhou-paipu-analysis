# v1.4.3

v1.4.3（1.4.x 线的正式版）。

## 相对 v1.4.0 的变化

- **新版 NAGA 模型支持**：新版 NAGA 报告里出现的「アナンタ / ウロボロス」按官方播放器口径接入，显示为 **NAGA-避四 / NAGA-争一**；第零类特征 5 → 7 项，特征总数 **42**（7 + 17 + 17 + 1）。
- **联合分布展示**（新模型）：决策表直接列出「打 3p」「打 3p立直」这类「打哪张牌 × 是否立直」的联合选项；概率条从中间一分为二（左半紫 = 默听、右半红 = 立直），高度各自独立。
- **完整动作空间**（新模型）：右侧 AI 决策面板补齐 自摸 / 荣和 / 九種九牌 / 暗杠（哪一张）/ 加杠（哪一张）—— 即报告在该帧给出的所有可选动作及其概率。
- **「其它」行按显示值补足**（v1.4.1）：决策表残差按表内已显示选项的显示值算到 100.0%（例如某张牌 99.54% 显示成 `99.5%` 时补一行 `其它 0.5%`）。
- **概率条配色统一**（v1.4.2）：默听条固定 `rgb(124,59,230)`、立直条固定 `#e0503a`，取消原先对最高概率项的高亮。
- **老模型零变化**：NAGA-平衡 / NAGA-超副露 / Mortal / 天凤牌谱的展示与 v1.4.0 之前一字未改（41 份旧 NAGA 报告 21,619 帧打牌分布 + 5,434 副露 + 195 杠 + 826 立直概率逐字节一致）。

## 新版 NAGA 模型的取值口径

- 打牌概率 = **默听支 + 立直支**（按官方播放器 1.2.2 的 `dahai_detail` 口径，末 3 档赤 5 并回普通 5）。
- 立直概率 = **立直支之和**（报告未直接给出时）。
- 因此新模型不再单独显示「立直」一行，而是与打牌合并成联合分布。
- 顺带修掉一个旧问题：此前 NAGA-平衡 的立直概率恒显示 `0.0%`（解析层把「按模型取值的标量列表」当成了单值）。

## 安装与升级

- Windows 安装包（NSIS 向导），安装到当前用户目录。
- **数据库结构版本 11**：只有「大版本 + 中版本」相同的软件与数据库才能互相使用（v1.4.0 / v1.4.1 / v1.4.2 / v1.4.3 之间互通，v1.3.x 与 v1.4.x 之间不互通）。
- 数据库结构在第 74 轮发生变化（新增两个 NAGA 模型的特征列）⇒ 用 v1.4.x 加载 **v1.3.x 及更早**建的库会提示「版本不兼容」，需要重新分析牌谱。
- 用户数据（牌谱 / 数据库 / 日志）保存在 `%LOCALAPPDATA%\tenhou-paipu-analysis\`，卸载不会删除。
