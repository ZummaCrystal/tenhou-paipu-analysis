# v1.5.1

v1.5.1（**1.5.x 线的补丁版**）：牌谱本地导入、全目录同局合并与决策面板修正。

## 新增

- **从本地导入牌谱**（第 83 轮）：牌谱下载页新增第三种模式，可一次选择单个 / 多个牌谱文件，或选择整个目录；文件会复制到指定子目录，并执行与下载相同的特征码判重和牌局合并。同名同内容直接跳过；同名不同内容自动在完整后缀前加 `-1` / `-2`，不覆盖已有文件。单文件上限 128 MB。
- **全目录同局合并与来源优先级**（第 83 轮）：判重范围从单目录扩大到整个 `data/paipu/`。同一局按来源优先级 `naga-new > naga > mortal > tenhou` 选择文件名与格式；合并容器只写一次，再复制到每个原先有同局文件的目录，每个目录各保留一份同名 `[mix]`，不同目录之间不互相删除。`naga-new` 按报告内容（新模型名或 `dahai_split` / `hora` / 杠候选等字段）识别，不再依赖目录名。纯天凤重复局只在同一目录内按特征码去重，不生成 `[mix]`。

## 修正

- **AI 决策面板不再误补「其它 100%」**：当一帧只有 100% 的立直或打牌、且没有可分摊概率的打牌分布时，选项表只显示真实动作，不再追加一条「其它 100%」。

## 兼容性

- **数据库结构版本仍是 11，特征口径未变**：v1.5.0 与 v1.5.1 同属 1.5.x，库可以直接继续扩充 / 检索，**不需要重新分析**。
- 从 1.4.x（含 v1.4.4）升级仍会因大 / 中版本不同提示数据库不兼容；旧库需删除后重新分析，牌谱文件不必重新下载。
- 用户数据（牌谱 / 数据库 / 日志）仍在 `%LOCALAPPDATA%\tenhou-paipu-analysis\`，卸载不会删除。

## 安装与升级

- Windows 安装包（NSIS 向导），只支持 Windows x64。
- 从 v1.5.0 升级无需处理数据库；从 1.4.x 升级需删除旧库并重新分析。
- 后端自检：`/api/health` 返回 `version 1.5.1`。
