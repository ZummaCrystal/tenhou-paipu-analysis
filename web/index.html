打不开文件 / 载入示例失败？

正常用法：在项目根目录启动本地服务，再打开页面地址。需要本地服务才能访问 data/ 牌谱、「牌谱分析」与「牌谱检索」：
python server.py
然后访问 http://127.0.0.1:8770/（页面文件在 web/index.html）。

也可以直接双击 web/index.html 用「选择牌谱文件」离线播放， 但牌谱分析与检索必须走本地服务。

牌谱分析

选择本地牌谱文件或一个子目录，对其中每一个非自摸的摸牌帧与每一个吃/碰后等待出牌的帧 （视角＝摸牌者本人；巡目按「出牌」计）标注 33 个特征（16 个第一类 + 17 个第二类：向听数 / 期望枚数 /

期望打点 / 危险筋组·两面组），写入本地 SQLite 数据库。

特征取值说明：三种向听数的内部取值 3 表示「>=3 向听」，界面与文档里一律显示成 >=3； 检索时按 >=3 填写条件即可。

牌谱检索

指定一个本地数据库文件，按「牌谱特征」检索打点帧（摸牌帧 / 吃碰后帧），输出： 牌谱特征码 + 局况 + 本场 + 巡目 + 风位，并可跳转到对应帧形态查看。

牌谱下载

把天凤牌谱下载到 data/paipu/<子目录>：可以输入单个牌谱 URL， 也可以选择一个「每行一个 URL」的本地文本文件；同名文件直接覆盖，下载完可直接拿去分析。

牌谱分析

选择一个牌谱文件或一个子目录，对其中每一个非自摸的摸牌帧与每一个吃/碰后等待出牌的帧 （视角＝摸牌者本人；巡目按「出牌」计）标注 33 个特征（16 个第一类 + 17 个第二类），写入本地 SQLite 数据库。分析由本地服务完成： 请先运行 python server.py，再从它打印的地址打开本页。

「同时写入原始数据（--full）」勾选与不勾选的区别

勾选：把每一帧的原始数据（手牌 / 副露 / 宝牌 / 分数）一起写进 frame_full 表， 以后新增特征时可以直接用旧牌谱重算；不勾选：只写 33 个特征值与定位信息，数据库更小 （约为勾选时的一半），但新增特征时必须重新分析牌谱。

本地数据库（data/db）

点「设为当前库」可把它选为牌谱检索使用的数据库。

路径怎么写 / 找不到 node？

相对路径按项目根目录解析，所以 data 就是项目里的 data\； 也可以直接写绝对路径（会递归扫描其中的 .xml 牌谱），例如 D:\paipu。

打点不用选工具：有 node.exe 时第一类特征由 node 打点、第二类 17 项由 python 补齐 （两者逐字段一致，有交叉校验测试）；没有 node 时全部走 python。

「扩充现有数据库」把本次牌谱追加进已有的库，库里已经有的牌谱（特征码相同）自动跳过； 数据库里记录了生成它的软件版本，版本不一致的库不能扩充，请删除后重新分析。

牌谱检索

先指定一个本地数据库文件，再逐条添加「牌谱特征」（支持全部 33 个特征： 16 个第一类 + 17 个第二类，不能重复添加），每条特征都要指定条件（互斥取值的特征用下拉选取， 整数特征填 整数 / 区间 / 列表 / 比较，期望枚数·期望打点等实数特征可填 0.5 / 0-1.5 / 0,1,2.5 / >=3）； 点「检索」返回同时满足全部条件的打点帧。 条目名＝牌谱特征码 + 局况 + 本场 + 巡目 + 风位，点击跳到对应帧形态查看； 跳转后右侧「当前帧特征」面板会列出该类全部特征与取值，检索用到的特征会高亮； 「全部浏览」则按顺序阅图，用「上一条目 / 下一条目」切换。
